# Guitar2MIDI — установка и настройка в Ableton Live 12 (Windows)

Плагин слушает гитару и в реальном времени превращает сыгранные ноты в MIDI.
MIDI уходит в виртуальный MIDI-порт (loopMIDI), а MIDI-дорожка в Ableton
принимает его и играет любым инструментом.

```
Гитара → звуковая карта → Аудиодорожка [Guitar2MIDI] ──(loopMIDI)──► MIDI-дорожка [любой синт]
```

> Почему не через Send? В Ableton посылы (Sends) передают только звук, а не MIDI.
> Порт loopMIDI работает так же, как «посыл MIDI»: одна дорожка отправляет,
> другая принимает.

---

## 1. Установить loopMIDI (один раз)

1. Скачайте loopMIDI с сайта автора: https://www.tobias-erichsen.de/software/loopmidi.html
2. Установите и запустите.
3. Внизу окна впишите имя порта, например `Guitar2MIDI`, и нажмите **+**.
4. Порт работает, пока запущен loopMIDI. Удобно включить его автозапуск:
   правый клик по значку в трее → *Autostart*.

## 2. Установить плагин

1. Распакуйте скачанный архив `Guitar2MIDI-Windows.zip`.
2. Скопируйте **папку** `Guitar2MIDI.vst3` в
   `C:\Program Files\Common Files\VST3\`
   (Windows спросит права администратора, нажмите «Продолжить»).
3. `Guitar2MIDI.exe` — отдельная версия без Ableton, она нужна только для быстрой проверки.
   Если Windows покажет «Windows защитила ваш компьютер», нажмите
   «Подробнее» → «Выполнить в любом случае». Файл не подписан, поэтому Windows так реагирует.

## 3. Настроить Ableton (один раз)

1. **Options → Preferences → Plug-Ins**: включите *Use VST3 Plug-in System Folders*
   и нажмите *Rescan*.
2. **Preferences → Audio**: Driver Type = **ASIO**, выберите свою звуковую карту.
   Buffer Size ставьте 128 или меньше, если компьютер справляется. Это задержка звука.
3. **Preferences → Link, Tempo & MIDI**: в списке MIDI Ports найдите
   `Input: Guitar2MIDI` (порт loopMIDI) и включите **Track = On**.
   Для `Output: Guitar2MIDI` всё оставьте **выключенным**, иначе возникнет MIDI-петля.

## 4. Собрать проект

**Дорожка 1 — гитара (Audio Track)**
- Audio From: ваша звуковая карта, вход, куда подключена гитара (например *1*).
- Monitor: **In**.
- Перетащите на дорожку плагин **Guitar2MIDI** (Plug-Ins → VST3).
- В окне плагина, в поле **MIDI out port**, выберите `Guitar2MIDI` (порт loopMIDI).
  Если порт не появился, нажмите **Refresh**.

**Дорожка 2 — инструмент (MIDI Track)**
- MIDI From: **Guitar2MIDI** (порт loopMIDI), канал *All Channels*.
- Monitor: **In**.
- Поставьте любой инструмент: Wavetable, Operator, Drift, Simpler или любой VST.

Играйте. В окне плагина будет видна нота, которую он отправляет,
а MIDI-дорожка будет её играть.

Чтобы **записать MIDI**, включите запись (Arm) на MIDI-дорожке и нажмите Record.
Записываются ноты, которые потом можно редактировать.

Если хотите слышать только синтезатор без гитары, выключите **Pass audio**
в плагине или поставьте громкость гитарной дорожки на минимум.

## Ручки плагина

| Ручка | Что делает | Когда крутить |
|---|---|---|
| **Gate** | Порог громкости, ниже которого ноты не играются | Шум или фон рождает ноты → поднимите. Тихие ноты теряются → опустите. Оранжевая риска на индикаторе уровня показывает порог |
| **Pick detect** | Насколько резким должен быть удар медиатора, чтобы считаться новой нотой | Повторные удары по той же ноте не пере-запускаются → уменьшите. Лишние повторы → увеличьте |
| **Tolerance** | Строгость определения высоты | Проскакивают ошибочные ноты → уменьшите. Слабые ноты не ловятся → увеличьте |
| **Stability** | Сколько кадров по 4 мс высота должна держаться, прежде чем прозвучит нота | Больше — меньше «мусора», но больше задержка |
| **Release** | Через сколько кадров без распознанной высоты нота отпускается | Ноты обрываются раньше времени → увеличьте |
| **Dynamics** | 0 — все ноты одной громкости, 1 — velocity зависит от силы удара | |
| **Lowest / Highest** | Диапазон нот | **Lowest ставьте на самую низкую открытую струну**: чем выше Lowest, тем меньше задержка. E2 для стандартного строя, D2 для Drop D |
| **Transpose** | Сдвиг MIDI в полутонах | +12 — на октаву выше, удобно для басовых партий синтом |
| **Pitch bend** | Передаёт бенды и вибрато | Включайте, если хотите «живые» подтяжки |
| **Bend range** | Диапазон pitch bend | **Должен совпадать** с диапазоном Pitch Bend в синтезаторе (посмотрите его в настройках синта; чаще всего это 2) |
| **Channel** | MIDI-канал | |
| **Pass audio** | Пропускать звук гитары дальше | |

## Советы для лучшего распознавания

- Подключайте гитару **в инструментальный вход** (Hi-Z / INST) звуковой карты.
- Плагин ставьте **первым** на дорожке, до любых эффектов. Дисторшн и хорус мешают распознаванию.
- Лучше всего работает звукосниматель у грифа (neck) и чистый звук.
- Играйте по одной ноте и глушите предыдущую струну: этот режим рассчитан на мелодии.
- Строй гитары: плагин показывает отклонение в центах, его можно использовать как тюнер.

## Задержка

Задержка распознавания составляет примерно 10–15 мс на высоких нотах и 25–30 мс
на нижних струнах. Это физика: чтобы узнать высоту низкой ноты, нужно
дождаться нескольких её колебаний. К ней добавляется задержка звуковой карты
(Buffer Size).

## Если что-то не работает

| Проблема | Решение |
|---|---|
| Плагина нет в Ableton | Проверьте, что папка лежит в `C:\Program Files\Common Files\VST3\`, и нажмите Rescan |
| В списке портов пусто | Запустите loopMIDI, создайте порт, нажмите Refresh в плагине |
| «Could not open this port» | Порт занят другой программой. Создайте в loopMIDI ещё один порт |
| MIDI-дорожка молчит | MIDI From = порт loopMIDI, Monitor = In, в Preferences у Input-порта включён Track |
| Ноты звучат «двойные» или зацикливаются | Выключите Track/Remote для **Output** порта loopMIDI в Preferences |
| Лишние ноты от шума | Поднимите Gate, уменьшите Tolerance |
| Ноты «зависают» | Нажмите Stop в Ableton дважды или выберите в плагине другой порт и верните обратно: плагин отпустит все ноты |
